layout(location = 0) in vec3 aPosition;          // slot 0 â† positions VBO (one per vertex)
layout(location = 1) in vec3 aNormal;            // slot 1 â† normals VBO

18The loader and the window manager

ObjModelLoader

  • Parsing: lines starting v are vertex positions; lines starting f are faces. OBJ indices start at 1, so it subtracts 1 (negative indices count from the end). A face with more than 3 corners is fan-triangulated: (first, i, i+1) for each i, the same fan used after clipping.
  • Normalizing the model: finds the bounding box (min and max of x, y, z), moves its centre to the origin, and scales so the largest side is 2 units. The bunny then always fits between âˆ’1 and 1, whatever units the file used.
  • Smooth normals: for each triangle, the face normal is the cross product (B âˆ’ A) Ã— (C âˆ’ A). It is added to all three of its vertices. Big triangles have longer cross products, so they count more (area-weighted). Finally each vertex's sum is normalized. Shared vertices get the average of their neighbours' directions, which makes the lighting smooth instead of faceted. The cross product order is the winding order: reversing it would flip every normal inward (the ice bunny's dark backside).
